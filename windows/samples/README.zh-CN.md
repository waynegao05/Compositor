# 中文验收样本

使用 CLI 生成标准工程，无需下载外部图片，也不依赖桌面显示服务：

```powershell
dotnet run --project windows/src/Compositor.Cli -c Release -- sample ./artifacts/Chinese-Acceptance
dotnet run --project windows/src/Compositor.Cli -c Release -- verify-sample ./artifacts/Chinese-Acceptance
```

从仓库根目录执行。生成目标必须不存在或为空，非空目录会被拒绝。完整样本先在临时目录生成并验证，再移入目标目录。
生成端需安装覆盖中文的系统字体，例如 Windows 的微软雅黑或 Linux 的 Noto Sans CJK SC。缺字时命令失败并提示安装字体。

生成结果：

| 文件 | 用途 |
|---|---|
| `中文验收工程.comp/` | 格式 11 的 960×640 工程，包含六个图层、可编辑中文、透明区域、正片叠底与横纵参考线 |
| `参考导出.png` | 根据工程导出的参考图 |
| `导入素材.png` | 256×160 原创透明图形，用于菜单导入、拖放与图像复制粘贴测试 |
| `验收步骤.zh-CN.md` | Windows 11 中文输入、保存重开、导出及缩放检查步骤 |

验收前复制完整样本，在副本中编辑。`verify-sample` 面向原始样本，固定内容被手工改动后验证失败符合预期。
它检查工程语义、保存重开、图层像素与导出图，临时产物随检查结束清理，原始工程保持不变。
非法命令参数、文件错误和验证失败均返回非零退出码，可用于 CI。

项目 ID、图层 ID、内容与布局固定；参考文字栅格依生成主机字体而定。跨平台重新编辑文字时，不要求字形、字距、抗锯齿完全一致。
自动检查不覆盖原生输入法窗口、真实系统缩放、资源管理器拖放或跨应用图像剪贴板，这些项目须在 Windows 11 实机完成。
启动时可以传入本地 `.comp` 文件夹、其中的 `manifest.json` 或图片路径，含空格的参数需加引号。
拖放按复制处理；便携包不会自动注册文件关联，也不会把路径转发给已有进程。文本和文件列表不属于图像剪贴板支持范围。
