## 本轮完成

- 保存前验证已有目标。普通文件夹、损坏工程、链接及含额外内容的工程均拒绝覆盖，避免递归删除无关内容。末尾带路径分隔符的工程也能正常保存。
- 修复画布文字编辑期间的保存与标签切换。保存前提交文字并建立撤销记录，切换或打开其他工程保留原标签文字。
- 单标签关闭覆盖新建未保存工程与尚未结束的文字编辑。重复关闭不会重复询问，关闭确认后又发生修改需要重新确认。
- 文字编辑期间拦截图像剪切、粘贴、填充等快捷键，保留保存、光标、删除、提交、取消及输入法处理。修复“恢复默认快捷键”错误地恢复为当前自定义设置的问题。
- 工程监听遇到目录重命名间隙、文件暂时不可读时保留当前画布，待可读时重试；存在文字编辑会话时不自动替换文档。异常版本数字及清单中的空元素按工程格式错误处理。
- 界面导入接通已有 PSD/PSB 解析器，作为新的未保存工程打开。支持解析器能读取的图层与合成图回退，显示转换说明；失败保留原工程。普通图片导入按剩余文档像素预算和图层上限检查。
- 新增常见工程与图片导入错误的中文说明，诊断保留原始异常。
- 新增 Windows 相机 RAW 运行库探测，使用真实 LibRaw 绑定检查加载能力。缺失时提示完整保留便携文件和检查微软 Visual C++ v14 x64 运行库，不自动下载或安装。
- 验收脚本和 CI 增加文字编辑、导入及运行库能力记录。明确文件拖放、系统剪贴板互通和启动参数打开尚未实现。

## 使用与兼容边界

1. 完整解压新的便携包，运行 `Compositor.Desktop.exe`。
2. PSD/PSB 通过“文件 → 导入图像”进入新的标签，随后另存为 `.comp`。部分 Photoshop 特性会转换或省略，请检查转换说明和实际图像。
3. 保存遇到“含额外文件”提示时，建议另存到全新路径。含自定义文件、未引用图片或系统生成的 `.DS_Store` 的工程可继续按原读取规则打开，但本版会拒绝直接覆盖。
4. 文字输入完成后可直接保存或切换标签。画布内文字选择、文字剪贴板与输入法重转换尚未补齐，复杂文字编辑可使用“编辑文字”对话框。
5. 包内 `diagnostics/Test-Windows.ps1` 记录 RAW 依赖探测。缺少该可选能力不会阻止其余基础编辑检查；探测成功也不等于所有相机文件均能解码。

`.comp` 仍使用格式 11。保存采用暂存目录和目录改名，若进程在两次改名之间突然终止，原工程可能留在旁边的 `.old` 备份目录中；自动恢复及掉电持久性保证尚未实现。

本轮未运行 Windows 11 实机测试、托管 Windows CI 或 macOS/Xcode 构建，也未推送远程仓库。PNG/JPEG 基础编辑包自带 .NET，RAW 功能另受原生依赖影响。
