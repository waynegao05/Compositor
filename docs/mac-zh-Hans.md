# macOS 简体中文支持

本轮为保留的 macOS 客户端增加 `en` 和 `zh-Hans` String Catalog，主资源文件为 `Compositor/Localizable.xcstrings`，包含 1,078 个条目。应用跟随 macOS 为该应用选择的语言，修改系统的应用语言设置后重新启动。当前未提供应用内语言切换。

## 实现范围

- 主菜单、常用按钮、工具栏、图层及滤镜面板、尺寸设置、快捷键编辑器和常见错误提示。
- SwiftUI 固定文字使用 String Catalog；动态标签及 AppKit 控件通过 `L10n.tr` 或带参数的 `L10n.format` 显示。
- 快捷键保留原有英文 `group`、`title`、`id` 和 `keyboardShortcuts.v1` 存储结构，只翻译显示字段。快捷键搜索同时匹配中文及英文名称。
- 混合模式菜单通过 `representedObject` 传递英文原始值，蒙版子菜单通过稳定的 `identifier` 判断功能。程序逻辑不再依赖这些菜单的显示语言。
- `.comp` 字段、枚举原始值、默认图层名称、用户输入的文件名和图层名不做翻译转换，项目格式版本不变。
- 移除上游 Sparkle feed 地址并关闭自动检查，避免此分支被官方英文安装包覆盖。只有配置本分支的 feed、签名公钥，并主动设置 `CompositorUpdatesEnabled` 后才应启用更新。

## 验证与限制

当前开发环境为 Linux，没有 Swift 编译器和 Xcode。已完成 String Catalog JSON 检查、英文回退值及格式参数检查、修改后 Swift 文件的语法解析、快捷键定义不变检查和 `git diff --check`。这些检查无法替代 macOS 构建及运行测试。

需要在 macOS 上继续完成以下验收：

1. 用 Xcode 构建 Compositor 并运行原有测试；分别以英文与简体中文启动。
2. 检查新建、导入、图层编辑、滤镜、保存、关闭确认和重新打开流程，确认中文没有截断或遮挡。
3. 先在英文界面保存自定义快捷键，再改用中文，确认键位保持且中英文搜索均可用。
4. 验证所有混合模式的选择和预览，以及蒙版子菜单的禁用状态。
5. 在中英文界面分别打开同一 `.comp`，确认图层名称、混合模式及其他保存值一致。
6. 核对 VoiceOver、中文输入法和少量含运行时诊断信息的提示。未匹配资源的动态诊断继续显示原英文，后续应逐项补充带参数的资源。

本分支的 macOS 源码基于已有 Windows 移植所携带的版本。本轮没有另外移植新版上游的命令面板，也没有修改 Apple 图像处理实现。

## 翻译来源与维护

部分初始译文参考 [mainanamisa/compositor-cn 的 l10n 分支](https://github.com/mainanamisa/compositor-cn/tree/l10n)，参考提交 `d282718`。本轮仅提取译文、统一术语及补充资源，没有合并其存储值修改。仓库原有 MIT 许可证及版权声明保留。

新增 UI 文案应在英文和简体中文资源中同时维护。不要把翻译后的字符串写入命令 ID、偏好键、枚举原始值或项目文件。带变量的提示使用格式参数，用户提供的名称作为参数原样插入。
