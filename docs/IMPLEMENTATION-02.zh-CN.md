# 中文 Windows 预览版第二轮修改记录

日期：2026-10-09。版本：`1.3.7-zh.2`。基于第一轮提交 `100981a` 继续开发。

## 本轮完成

- 修复“另存为”失败后仍切换项目路径的问题。只有写盘成功才更新路径、已保存状态、监视器与最近项目；文件选择期间切换标签也只影响原标签。
- 增加主窗口关闭保护，覆盖所有标签与新建未保存工程。重复关闭只保留一个确认流程；选择“保留”或关闭确认框保留编辑；确认期间再次修改需要重新确认。
- 增加本地启动与异常日志，包括版本、运行时、系统架构、语言及窗口缩放。默认保留最近 8 份日志，每份最多 256 KiB，重启后可导出此前会话。
- “帮助”菜单增加诊断导出与打开日志文件夹；便携包提供双击入口 `Run-Diagnostics.cmd`。日志错误不阻止主功能，无法写日志时仍可导出环境说明。
- 修复版本信息丢失 `zh.2` 后缀的问题。无效或不完整的诊断命令返回错误码，避免误启动界面阻塞自动检查。
- 增加翻译资源与静态显示键检查，修复污点修复状态栏 3 处漏译。动态文案继续列入人工审查边界。
- 自动界面检查使用临时配置目录，避免改写真实的最近项目、工具、快捷键与语言设置。
- 增加标准中文工程及参考 PNG，包含六个图层、中文文本、透明区域、混合模式与参考线。生成器拒绝非空目录；验证器不修改输入样例。
- 更新 Windows CI、便携打包及 Windows 实机检查脚本。完整检查先保存此前日志，再运行检查，避免日志轮转丢失原问题记录。

## 如何在 Windows 11 继续验收

1. 将新便携 ZIP 解压到新的文件夹，运行 `Compositor.Desktop.exe`。
2. 将 `samples/Chinese-Acceptance/` 复制到可写目录，按内附步骤检查导入、中文编辑、保存重开与导出。
3. 如需自动记录，运行包内 `diagnostics/Test-Windows.ps1`。只导出日志可双击 `Run-Diagnostics.cmd`。
4. 按 `Windows11-验收步骤.md` 检查微软拼音、125% 至 200% 缩放、多屏、剪贴板与拖放。
5. 反馈版本、复现步骤、截图和必要诊断文件。诊断可能含错误中的文件路径，分享前可先检查。

本轮没有改变 `.comp` 格式、命令标识或用户图层名称，没有自动上传诊断数据。
