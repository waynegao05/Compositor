日期：2026-10-09。版本：`1.3.7-zh.4`。基于第三轮提交 `4063f2e`。

## 本轮完成

- 保存目录交换前登记事务，记录临时工程及旧工程的内容指纹。正常保存只清理该事务拥有且验证一致的备份；失败后保留已登记的有效副本。
- 同一工程的保存与恢复使用进程间锁，锁定期间完成目标校验和目录交换；其他实例长时间占用时明确拒绝，避免同时改写事务记录。
- 启动时检查中断保存，也可从“文件 → 恢复中断的保存…”进入。用户选定候选后，恢复到全新的工程路径，保留原工程与备份。损坏、变更、已恢复或链接候选会被拒绝。
- 接入本地文件拖放与启动路径参数。工程目录或其 `manifest.json` 打开为标签；PSD/PSB 复用分层导入；普通图片导入当前工程。重复路径去重，单项失败继续后续项，并显示处理结果。原工程目录因中断而缺失时，仍进入恢复检查。
- 接入系统图像剪贴板。复制、合成复制及剪切发布图像；粘贴读取当前系统内容，支持空窗口建立未保存工程。队列保证复制顺序，异步粘贴在标签、文档、编辑版本或确认状态变化后取消。
- 补充中文提示和失败信息，静态翻译检查扩展到 `MainWindow` 的拆分文件。
- Windows 验收脚本与 CI 新增恢复、剪贴板、外部文件检查，并同步包内中文说明。

## 使用与兼容边界

1. 完整解压便携包，运行 `Compositor.Desktop.exe`。已有设置继续使用，工程格式仍为 11。
2. 恢复登记默认在 `%APPDATA%\Compositor\Recovery`，图像副本保留在原工程旁。恢复要求新的目标目录；恢复后确认内容，再自行处理不需要的旧副本。启动检查最多读取最近 256 份事务记录。
3. 仅已经登记并留下有效副本的保存事务可恢复。没有定时自动保存，尚未保存的编辑、登记前中断和旧版本未登记备份不在本流程内；不承诺掉电后所有写入均可恢复。
4. 启动命令可包含多个本地路径，中文和空格路径分别加引号。拖放不移动源文件。本版没有文件关联注册，也没有向已运行实例转发启动参数。
5. 图像剪贴板使用 Avalonia 位图接口。Windows PNG/DIB 透明通道、与画图或浏览器互通、退出后仍可粘贴，均需要 Windows 11 实机验证。文本或空剪贴板不会回退粘贴旧图像。
6. 剪切发布失败时应用内副本保留，剪切可以撤销；系统剪贴板被占用时显示错误，请释放占用后重新复制。基础 PNG/JPEG 编辑包自带 .NET，相机 RAW 仍需要 Visual C++ v14 x64 运行库。

本轮未运行 Windows 11 实机测试、托管 Windows CI 或 macOS/Xcode 构建，也未推送远程仓库。
