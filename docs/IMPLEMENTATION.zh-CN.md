# 中文与 Windows 11 第一轮修改记录

日期：2026-10-09。Windows 预览版版本：`1.3.7-zh.1`。

## 来源与范围

原项目为 `robbietilton/Compositor`。本轮以 `chenguisen/Compositor` 的 `compositor_win` 分支
提交 `c51be1e57d699edce857115f43bbca579f18dcd4` 为开发基线，保留 macOS Swift 客户端，
在已有 .NET/Avalonia Windows 移植上完成简体中文及 Windows 发布流程。
当前 Windows 功能基线跟随 1.3.7；此次没有把最新上游功能全部迁移到 Windows。

## 本地验证

环境为 Ubuntu 24.04 x86_64、.NET SDK 10.0.401、PowerShell 7.5.3。
中文渲染验证使用系统安装的 Noto Sans CJK SC；没有将该字体嵌入应用。

| 检查 | 结果 |
| --- | --- |
| Release 解决方案构建，警告视为错误 | 0 警告，0 错误 |
| 核心测试 | 878 通过，0 失败，0 跳过 |
| 中英文菜单、快捷键重绑、Unicode 项目保存与重新打开 | 通过 |
| 中英文指针交互：绘画、选区、参考线、文本和颜色面板 | 通过 |
| IME 接口契约检查 | 中文与英文各 30 项通过 |
| Windows x64 自带运行时跨编译 | 通过 |
| ZIP 完整性、PE x64 格式、运行时与许可证包含检查 | 通过 |
| macOS 资源格式、格式参数及修改后 Swift 语法检查 | 通过静态检查 |

图形检查使用 Avalonia headless 与 Skia 实际绘制。它可以发现中文缺字、菜单与控件逻辑问题，
但不能代替 Windows 桌面的真实窗口、输入法或设备行为。
曾发现 Linux 原生字体库不匹配，已统一版本；切换依赖后清理重建以移除旧输出。
核心测试含固定耗时阈值的性能断言，记录中的完整通过结果是在没有并行图形任务时获得的。
